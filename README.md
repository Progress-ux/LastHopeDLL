# Last Hope (library)

## Clone repository

```bash
git clone https://github.com/Progress-ux/LastHopeDLL.git
cd LastHopeDLL
```

### Install Metamod-P
```bash
git clone https://gitlab.com/sven-coop-tools/metamod-p.git
```

### Install ReGameDLL_CS
```bash
git clone https://github.com/s1lentq/ReGameDLL_CS.git
```

## Make library
```bash
make
```

or make with `bear`:

### Install bear
```bash
sudo pacman -S bear
```

## Make library with bear
```bash
bear -- make
```
